# 风控增量运行约定

默认不启用新增 IP 风控，保持当前认证行为。仅当 `CAREOLD_RISK_DATA_DIR` 为非空目录时，进程启动加载风险规则和补充事件，失败则中止启动，不静默丢弃策略。目录必须为当前服务账号私有，且同一目录只能由一个服务器实例持有；此实现不提供跨进程文件锁或分布式规则同步。多副本部署不能共享该 JSON 文件，应先换用数据库/持久化队列。

可选的 `CAREOLD_RISK_PROXY_CIDRS_FILE` 加载可信本地 CIDR 列表；`CAREOLD_RISK_NETWORK_FEED` 加载六列 CSV：`cidr,kind,confidence,observedAt,provider,source`。启动时读取，更新后重启生效；请求期间不读文件、查询外部 IP 服务或 DNS。库保留 StartNetworkRefresh API，调用者必须提供取消 context；服务器没有隐式周期刷新。不能依赖请求头识别真实硬件身份或准确检出所有代理。网络来源若为空，不凭空判定 VPN。

仅在明确启用时，连续验证失败产生临时账号+IP 或 IP 冷却；管理员可创建/删除 block 与 skip-auto 规则。block 优先，skip-auto 只跳过新增自动风控，不跳过密码、MFA、现有 SQL 登录限额、会话/岗位权限或 CSRF。设备 SOS、设备上报及照护回执路径不经过这些登录/邀请码风控判断。

JSON 事件在内存有界保存，250ms 合并写盘；慢盘不会阻塞单纯记录事件，但管理员规则变更需等待同步保存，核心锁仍可能在此期间影响认证。SQL login_audit 保持原有同步权威审计。JSON 只是补充信号，进程崩溃/磁盘故障/系统异常可能丢事件；250ms 是正常调度周期，不能保证故障下最多只丢 250ms，更不是零丢失。禁止把它替代合规、可靠性要求更高的持久审计队列。

main 在 HTTP 请求排空和数据库工作线程停止后调用 Close，并记录最终刷盘错误。Close 可重复调用，完成后不能再修改规则；Persist 只能初始化一次。事件最多 2000 条，查询/追加/加载时裁剪超过 30 天记录；无新写入时磁盘上的过期条目可能保留到下一次快照更新，不提供定时安全擦除保证。规则最多 4096 条；加载快照最大 16MiB，CSV 最大 64MiB，CIDR/CSV 行数受限。未配置持久目录的库实例仅用于内存测试，服务器不会把这种实例作为已启用服务发布。
